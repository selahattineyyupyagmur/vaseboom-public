# VaseBoom: public files

Public files of **VaseBoom**, a physics game about smashing vases with a slingshot by SEYA Venture.
This repository holds no code.

- **Music:** one piece per tower floor, in the [releases](../../releases). Every piece is free to use (CC0, or CC BY with the artist named); see `CREDITS.txt`.
- **Legal pages:** privacy policy and terms of use, in Turkish and English, published at
  https://selahattineyyupyagmur.github.io/vaseboom-public/legal/
